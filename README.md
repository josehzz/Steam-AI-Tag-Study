# Steam AI Tag Study

An interactive data study analyzing the relevance and impact of the Steam AI disclosure tag across 63,798 games released between January 1, 2024 and November 2, 2026.

## Live Site

Hosted via GitHub Pages at: https://josehzz.github.io/Steam-AI-Tag-Study/
